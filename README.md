# drawGPT

a bunch of sampled mountains from my very first experiment:

![mnt0](./doodles/0/mnt0.gif) ![mnt1](./doodles/0/mnt1.gif) ![mnt2](./doodles/0/mnt2.gif) ![mnt3](./doodles/0/mnt3.gif)

in the first experiment, I trained a minimal gpt model (n_layer=6, n_head=6, n_embd=384) on my laptop, using a subsampled version of quickdraw (only 22 classes), for only ~32,000 steps. 
the training loss reached around 4.5-5. 

samples were generated with top_k=64 and temperature=1.0.
